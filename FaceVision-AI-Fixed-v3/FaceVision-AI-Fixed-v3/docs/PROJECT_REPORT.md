# FaceVision AI — Project Report

## Abstract
FaceVision AI is a local desktop application that combines computer vision, face embeddings, SQLite storage and attendance management.

## Objectives
- Detect faces from images/webcam streams.
- Register identities and local embeddings.
- Match recognized faces against registered data.
- Record attendance with timestamps.
- Provide searchable/exportable attendance data.
- Demonstrate modular software engineering.

## Technology
Python, OpenCV, NumPy, Tkinter, SQLite and CSV.

## Future Enhancements
- Modern deep face embeddings.
- Liveness/anti-spoofing.
- Multi-camera support.
- Role-based access.
- Encrypted biometric storage.
- Rich analytics and charts.
