# User Guide

1. Install dependencies.
2. Run `python app.py`.
3. Use **Register Face** to add a person from a clear face image.
4. Use **Face Manager** to inspect/remove registrations.
5. Use **Attendance** to search attendance records.
6. Use **Export CSV** to create a spreadsheet-compatible export.
7. Use **Generate Report** to create a Markdown project report.
8. Use **Seed Demo Data** to populate the application without a webcam.

The current portfolio build focuses on the data/recognition foundation and desktop management workflow. A live webcam recognition screen can be added as a separate view using the existing detector, encoder and recognizer classes.
