# ✨ Features - 




📷 Real-time webcam face detection


🧑 Face registration with Name & ID


🔐 Face recognition


🟢 Known / 🔴 Unknown face detection


📝 Automatic attendance


⏱️ Date & time tracking


📊 Attendance dashboard


🔎 Search attendance records


📁 CSV export


🖼️ Face management


⚙️ Application settings


🧪 Demo data mode


📄 Automatic report generation


🖥️ Professional desktop GUI



# 🛠️ Tech Stack



Python • OpenCV • NumPy • Pillow • SQLite • Tkinter




# ⚙️ How It Works - 


Webcam / Image

      ↓

      
Face Detection

      ↓
      
      
Face Encoding

      ↓
      
Face Recognition

      ↓
      
Known / Unknown

      ↓
      
Automatic Attendance

      ↓
      
SQLite Database


      ↓
      
Dashboard / CSV / Reports

# 🚀 Run Locally


Recommended: Python 3.11 or 3.12


pip install -r requirements.txt

python app.py


# Windows: You can also double-click run.bat.



# 🧪 Run Tests


pytest -q


# 🎯 Project Goal



FaceVision AI demonstrates practical skills in Computer Vision, Face Recognition, Python, GUI Development, Database Management, and Machine Learning concepts.



Note: This project is intended for educational and portfolio purposes. The default lightweight recognition implementation is not designed as a production-grade biometric security system.
